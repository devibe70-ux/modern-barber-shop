# 💈 The Modern Barber Shop (Urban Grooming Lounge)

> **Starter Tier Core Presence & Advanced Business Booking Platform**
> Built with React 19, Vite, Tailwind CSS v4, Lucide Icons, and Node.js Express.

![The Modern Barber Shop](https://images.unsplash.com/photo-1503951914875-452162b0f3f1?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

1. **Dark Mode Industrial Aesthetic:**
   - Deep Slate (`#121212`), Gold Accents (`#D4AF37`), High-Contrast Typography (`Cinzel` & `Plus Jakarta Sans`), and glassmorphism cards.

2. **Flagship Mobile Experience:**
   - Sticky Mobile Action Bar anchored at bottom of mobile viewports with one-tap **"Call Now"** (`tel:`) and **"Get Directions"** (Google Maps navigation).

3. **7 Interactive Application Pages:**
   - **Home:** Hero section, 4 value pillars, featured services preview, and verified 5-star Google customer reviews.
   - **Appointment Booking:** 4-step interactive reservation wizard (*Service ➔ Barber ➔ Date/Time Slot ➔ Customer Details*).
   - **Services & Rates:** Categorized menu with price tags, durations, descriptions, and category filter tabs.
   - **Lookbook Gallery:** Filterable haircut portfolio with interactive Lightbox Modal zoom.
   - **About Team:** Master barber bios, specialty badges, experience counters, and Instagram handles.
   - **Payment & Invoice:** Checkout portal (*Pay at Shop Lounge vs Pre-Pay Online*) with printable digital receipt generator.
   - **Contact & Location:** Interactive Google Maps pin, **Share Location** link copier, live Open/Closed badge, and inquiry form.

4. **Express Node.js Backend API:**
   - Endpoints on `/api/contact` and `/api/appointments` handling payload validation and Nodemailer email notifications.

## 🚀 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Start backend API server
npm run server
```

---

## 📦 Building & Deployment

```bash
# Create production build
npm run build

# Deploy automatically to GitHub Pages
npm run deploy
```
